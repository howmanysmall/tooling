---
title: completions
description: Generate shell completions for bash, fish, or zsh.
---

```text
darkroom completions <bash | fish | zsh>
```

Prints a completion script for the shell to stdout. Completions fill in commands, options, model IDs, parameter
values, and run IDs. Option values follow the model: with `-m` on the command line, `-a`, `-r`, and `-q` complete
only what that model accepts. In fish, run IDs come with their date, model, and prompt.

To enable them, add one line to your shell's startup file. See
[Shell completions](/tooling/darkroom/guide/install#shell-completions).
