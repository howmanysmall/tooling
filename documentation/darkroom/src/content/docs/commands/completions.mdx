---
title: completions
description: Generate shell completions for bash, fish, or zsh.
---

```text
darkroom completions <bash | fish | zsh>
```

Completions fill in commands, options, model IDs, and run IDs. Option values follow the model: with `-m` on the
command line, `-a`, `-r`, and `-q` complete only what that model accepts. In fish, run IDs come with their date,
model, and prompt.

```sh title="~/.bashrc"
source <(darkroom completions bash)
```

```sh title="~/.zshrc"
source <(darkroom completions zsh)
```

```fish title="~/.config/fish/config.fish"
darkroom completions fish | source
```

Open a new shell, or source the file again, for changes to take effect.
