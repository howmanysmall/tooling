---
title: Costs and paid requests
description: How darkroom estimates a cost before you spend it, and why it never sends a paid request twice.
---

Every image costs money on OpenRouter, so darkroom is careful with each request.

## Estimates

Before a request goes out, darkroom estimates its cost from the model's published prices. A model that charges by the
token has no fixed price per image, so darkroom uses what that model has cost you before. When it has nothing to go on,
it says the cost is unknown instead of guessing.

The prompt box shows the price of the chosen model, and the confirmation shows the estimate for the whole request.

## Sent once

A paid request is sent once. darkroom never retries it, because a retry after the provider already made the image would
charge you twice. If the connection drops after the request went out, darkroom tells you the request may still have
been charged and points you to [OpenRouter's activity page](https://openrouter.ai/activity) before you try again.

Free lookups, such as the model list, do retry, for up to 30 seconds.

## Nothing paid is lost

Each image is copied into the history before anything else can fail. If darkroom can't write your own copy, because the
disk is full or the folder is read-only, the history copy is still there and the error names it. Press `ctrl+c` while
an image is being saved and darkroom finishes saving it first.
